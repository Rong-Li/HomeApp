## Month-menu compatibility follow-up

- Reproduced the user's disabled menu with an old API fixture (missing monthly
  snapshot fields), both in native checks and a failing simulator UI test.
- Added an expense-endpoint fallback for old/partial responses. It computes UTC
  monthly snapshots with Decimal sums, expense categories, refunds, and counts;
  complete new API responses do not trigger this extra request.
- Independent review found fallback failure could hide valid yearly reports and
  partial responses could disagree between Current Month and the same menu month.
  Both issues were reproduced with failing native checks and fixed.
- Verification: native checks pass including empty years, refunds/cents, year
  boundaries, old/partial/error responses; final production simulator build passes;
  all four simulator UI tests pass (zero failures/skips), including opening Month
  and selecting February with the old API fixture. Whitespace checks pass.
- Tradeoff: fallback monthly values use transactions, while trend/yearly views
  retain stored reports. No deployment or live API calls were performed.

## Tab-switching and on-demand month follow-up

- Reproduced redundant work offline with real tab views/APIService and 4,000 fake
  transactions: three round trips increased GET requests from 9 to 36.
- Added shared in-flight tab loading and a 60-second success freshness interval;
  the same round trips then stayed at 9 requests. Manual refresh bypasses freshness,
  and failed refreshes invalidate it. Insights reports success only if every fetch succeeds.
- At the user's request, removed the automatic year transaction fallback entirely.
  Month selection loads only that month's UTC date range and caches the result.
  Complete report responses still display their existing snapshots immediately;
  old responses show a month-selection prompt until a month is selected.
- Verification: production simulator build and both native check suites pass.
  The final simulator suite could not launch its runner (Mach error -308); the
  focused month-click test passed on a separate iPhone 16 simulator retry.
- No commits, pushes, or live financial API calls made for this follow-up.
